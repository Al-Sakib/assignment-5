Short answers to common DOM questions.

Question-1: What are the different ways to select an element in the DOM?

  • document.getElementById("id") – returns the single element with that id.
  • document.getElementsByClassName("cls") – returns a live HTMLCollection.
  • document.getElementsByTagName("div") – returns a live HTMLCollection by tag.
  • document.querySelector(".cls") – returns the first element matching any CSS selector.
  • document.querySelectorAll(".cls") – returns a static NodeList of all matches.
  • Relative traversal: parentElement, children, nextElementSibling, closest().

Question-2: What is the difference between innerHTML, innerText, and textContent?

  • innerHTML – gets/sets the HTML markup inside an element. Tags in the string are parsed into elements (be careful with untrusted input – XSS risk).
  • innerText – gets/sets the rendered text. It respects CSS (hidden elements are skipped) and triggers a reflow, so it is slower.
  • textContent – gets/sets all the raw text of the node and its descendants, including hidden elements and <script> text. It is fast and does not parse HTML.

Question-3: What is event delegation in the DOM?

Event delegation means attaching a single listener to a parent element instead of one on every child. Because events bubble up, the parent can catch events from its children and use event.target to find which child triggered it. It saves memory and also works for elements added later.

document.querySelector(".cards").addEventListener("click", (e) => {
  if (e.target.matches(".complete-btn")) {
    console.log("Clicked:", e.target);
  }
});

Question-4: What is event bubbling in the DOM?

Event bubbling is the way an event travels after it fires: it runs the handlers on the target element first, then moves up through each ancestor (parent, grandparent … document). You can stop it with event.stopPropagation(). The opposite direction (top-down) is the capturing phase, enabled with addEventListener(type, fn, true).

Question-5: How do you create, add, and remove elements using JavaScript?

  • Create: document.createElement("li"), then set textContent, classes or attributes.
  • Add: parent.appendChild(el), parent.append(el), parent.prepend(el), parent.insertBefore(el, ref) or el.insertAdjacentElement(pos, newEl).
  • Remove: el.remove() or parent.removeChild(el).
const li = document.createElement("li");
li.textContent = "New task";
document.querySelector("ul").appendChild(li);   // add
li.remove();                                    // remove
